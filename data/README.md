# LANDSIGHT — Data Directory

## Raw Data Sources

| Folder | Source | Format | Notes |
|--------|--------|--------|-------|
| dem/ | SRTM 30m / ASTER | .tif (raster) | Download from USGS EarthExplorer |
| rainfall/ | IMD Gridded / GPM IMERG | .nc / .tif | IMD API or GIOVANNI |
| soil_moisture/ | ISRO Bhuvan / NASA SMAP | .tif | Bhuvan portal |
| land_cover/ | Bhuvan LULC / Sentinel-2 | .tif / .shp | Bhuvan or ESA Copernicus |
| road_network/ | OSM + NRSC | .shp | OpenStreetMap Overpass API |
| village_hospitals/ | Census 2011 + HMIS | .csv / .shp | data.gov.in |
| historical_landslides/ | Bhukosh / NGDR / GSI | .shp / .csv | bhukosh.gsi.gov.in |

## Processed Data (Auto-generated by pipeline)

| File | Generated by | Description |
|------|-------------|-------------|
| feature_matrix.csv | M1 | One row per grid cell, all features merged |
| risk_scores.geojson | M2 | Landslide risk probability per cell |
| confidence_layer.geojson | M3 | Decision confidence per cell |
| road_exposure.geojson | M4 | Road vulnerability scores |
| graph_nodes.json | M5 | Village/hospital graph nodes |
| graph_edges.json | M5 | Road segment graph edges |
| criticality_scores.json | M6 | Ranked corridors by criticality |
| action_recommendations.json | M7 | Tiered action plans |
| risk_trajectory.json | M9 | Time-series pipeline run history |

## Target District

**Default: Kohima District, Nagaland**
Bounding Box: 25.4°N–26.2°N, 93.8°E–94.6°E

Change in `.env` to switch to another NE India district.
